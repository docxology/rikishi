# Introduction

The Suggested Upper Merged Ontology (SUMO) provides reusable classes and
relations for knowledge representation [@niles2001sumo]. Rikishi exposes
the source expressions and an asserted-edge projection for browsing
[@friedman2026rikishi]. The graph helps a reader find adjacent terms,
while the formula text lets the reader recover quantifiers, argument
order, and conditions. Confusing these views can turn the consequent
of an implication into an apparently asserted fact.

This companion study asks what the Python index preserves in each view
and which source details an operator can retrieve for an inspected term.
