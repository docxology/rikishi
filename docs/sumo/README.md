# Ontology and source language

The Suggested Upper Merged Ontology (SUMO) combines a reusable vocabulary with
logical axioms. Its Standard Upper Ontology Knowledge Interchange Format
(SUO-KIF) language expresses those commitments. These guides introduce the
ideas before the operator's measured projections and experiments.

| Reading order | Guide | What it explains |
| --- | --- | --- |
| 1 | [Ontology commitments](ontology.md) | Entities, classes, membership, specialization, signatures and permitted models. |
| 2 | [Source language](language.md) | Formula structure, terms, variables, scope, context and translation requirements. |
| 3 | [Systems](systems.md) | Sigma, target logics, theorem provers, lexical mappings and related ontology approaches. |
| 4 | [Worked source demonstrations](sumo-demonstrations.md) | Actual pinned formulas, argument roles, categories and source provenance. |
| 5 | [Ontology analysis](ontology-analysis.md) | Search, complete formulas, asserted-edge graphs, filters and structural diagnostics. |
| 6 | [Modeling](modeling.md) | Domain referents, proposed extensions, constraints and competency questions. |

Use [metrics](metrics.md) for exact measurement denominators,
[upstream contribution methods](contributing-upstream.md) for a reproducible
finding, and the [ontology–mathematics–simulation guide](sumo-fep-simulations.md)
for the scientific modeling connection. The [primary-source ledger](../research/scholarship.md)
connects the explanations to the literature and pinned implementations.
