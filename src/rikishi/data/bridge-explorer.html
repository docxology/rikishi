Finite free energy and ontology bridge

One set of rational inputs, three separate obligations: finite Free Energy Principle (FEP) calculations, selected Suggested Upper Merged Ontology (SUMO) reasoning, and concrete Lean statements.

Terms: Kullback–Leibler (KL) divergence; Knowledge Interchange Format (KIF). E theorem prover and Vampire theorem prover (V) provide the recorded native outcomes. This Hypertext Markup Language (HTML) page embeds JavaScript Object Notation (JSON); hashes use the 256-bit Secure Hash Algorithm (SHA-256).

Authored interpretation is not semantic proof transfer. A SUMO existential result does not identify a named numerical result. Binary LogFn is distinct from Lean’s unary natural logarithm Real.log. These first-order logic (FOL) cases encode no probability arithmetic or logarithm laws and establish no general preservation theorem or whole-ontology consistency.

This offline page displays retained evidence and computes local floating-point visualizations. It executes no prover, compiler or native replay, authenticates no proof-calculus steps, and makes no empirical FEP claim.

Exact scope of the displayed energy identity
For pᵢ = prior mass and ℓᵢ = P(observed true | state i), jᵢ = pᵢℓᵢ, Z = ∑ᵢjᵢ, and rᵢ = jᵢ/Z. The finite calculation is F(q) = ∑ᵢ qᵢ ln(qᵢ/jᵢ), surprise = −ln Z, and KL(q ∥ r) = ∑ᵢ qᵢ ln(qᵢ/rᵢ). Thus F = surprise + KL. This numerical identity is separate from the generated Lean theorem inventory and the SUMO predicates.
